## 💻 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/priyanshu0093/PortFolio.git
cd PortFolio
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 3. Build for Production
```bash
npm run build
npm start
```
